# CineQuery — MovieLens × BigQuery

**Live URL:** https://cinequery-183604469593.europe-west1.run.app/

A Streamlit movie search app connected to Google BigQuery (MovieLens 20M dataset), enriched with TMDB movie posters and cast information.

## Features
- Search movies by title
- Filter by language, genre, release year, and minimum average rating
- Movie detail page with poster, cast, overview and ratings
- All SQL queries logged to the terminal

## Tech Stack
- Streamlit
- Google BigQuery
- Google Cloud Run
- Docker
- TMDB API
